# SmartCart Customer Segmentation

An unsupervised machine learning project that segments SmartCart customers based on their demographic and purchasing behavior.

## Approach

* Data preprocessing & feature engineering
* Feature scaling
* PCA for dimensionality reduction
* K-Means & Agglomerative Clustering
* Cluster analysis and visualization

## Dataset

Customer demographic, spending, purchasing, and campaign-related data.

## Results

Identified **4 distinct customer segments** and analyzed their characteristics to derive actionable customer insights.

## Tech Stack

Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn · Jupyter Notebook

## Run

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
jupyter notebook
```

Open `smartcart.ipynb` and run the cells sequentially.
